## 🧠 Overview

Smart Interview Simulator AI is a **full-stack web application** that replicates real-world interview processes and provides **intelligent feedback, scoring, and improvement insights**.

It helps users prepare for interviews through structured rounds and data-driven analysis.

---

## 🔥 Key Features

### 🎯 Smart Interview Flow

* Role-based interview selection
* Experience-based logic:

  * **Fresher → Aptitude → Technical → HR**
  * **Experienced → Technical → HR**

---

### 🧪 Aptitude Round

* MCQ-based questions
* Timer functionality
* Instant evaluation

---

### 💻 Technical Round

* Role-specific questions
* Conceptual + coding-based answers
* Structured response input

---

### 🗣️ HR Round

* Behavioral interview questions
* Communication analysis
* Feedback generation

---

### 📊 Evaluation System

* Multi-dimensional scoring:

  * ✔ Correctness
  * ✔ Depth
  * ✔ Clarity
  * ✔ Examples
* Weakness detection
* Best practice suggestions

---

### 📈 Final Report

* Round-wise performance
* Overall score
* Strengths & weaknesses
* Learning recommendations

---

### 📊 Analytics

* Integrated tracking using Google Analytics

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```
git clone https://github.com/your-username/smart-interview-ai.git
cd smart-interview-ai
```

### 2️⃣ Create Virtual Environment

```
python -m venv venv
venv\Scripts\activate
```

### 3️⃣ Install Dependencies

```
pip install flask
```

### 4️⃣ Run Application

```
python app.py
```

### 5️⃣ Open Browser

```
http://127.0.0.1:5000/
```
